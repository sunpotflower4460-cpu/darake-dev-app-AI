# Phase 3 準備: 読み取り導線の設計

## 目的

Phase 3では、開発状況をアプリ内で見られるようにする準備をします。

最初に扱う対象は、次の4つです。

- リポジトリの概要
- 作業依頼の一覧
- 変更提案の一覧
- チェック結果の状態

## 今回やること

この段階では、まだ実際の取得処理は始めません。

まずは、画面上に以下を用意します。

- どの情報を読む予定か
- それぞれの現在状態
- 手動で止める場所
- 次に必要になる準備

## まだやらないこと

- 接続情報の入力
- 本番操作
- 書き込み操作
- 自動マージ
- 提出処理

## 手動ゲート

実際にGitHub上の情報をアプリへ表示する前に、ユーザー確認で止めます。

確認する内容は次の通りです。

- どのリポジトリを対象にするか
- どの範囲まで読ませるか
- 書き込みを許可しないこと
- 表示だけで進めること

## 完了条件

- Phase 3準備画面がある
- 読み取り予定の項目が見える
- 手動確認の場所が分かる
- 実接続前に止まる設計が見える
