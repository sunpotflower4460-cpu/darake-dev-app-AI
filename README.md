# Darake Dev App AI

AI開発をできるだけやさしく、自動化し、安全ゲート付きで進めるための開発管制室アプリです。

## 目指す体験

```text
ユーザー: こんなアプリが作りたい
  ↓
アプリ: 設計図を作ります
  ↓
アプリ: 段階に分けます
  ↓
アプリ: Phaseごとに実装・確認・レビューを進めます
  ↓
アプリ: 必要な場所だけ止めて通知します
  ↓
ユーザー: もっとこうしたい
  ↓
アプリ: 改善計画を作って再実行します
  ↓
アプリ: 提出準備の情報を同じ場所にまとめます
```

## Phase 2で強化したこと

- 種から生成された計画の表示
- 確認エージェントの役割表示
- 進行タイムライン
- スクリーンショット確認予定のカード
- 止めるタイミングと通知方針の見える化

## Phase 2.5で強化したこと

- 表示モードの確認欄
- 将来育てる場所の整理
- 仮データで動いている欄の見える化
- 実運用に進む前の安全な境界づくり

## Phase 3.6で強化したこと

- `scripts/buildState.mjs` で `public/repo-state.json` を更新する導線
- `npm run state:build` コマンド
- 手動実行専用の `Update State File` workflow
- 変更がある時だけ状態ファイルをコミットする仕組み

## 初期版でできること

- 魂・種の入力
- 設計図の確認
- Phase分解の確認
- 確認ゲートの見える化
- 自動スクショ確認の予定表示
- App Store提出準備フォームの入口
- 開発状況スナップショット表示

## 初期版でまだやらないこと

- 本番DB接続
- 課金
- 認証
- App Storeへの実提出
- 危険な自動実行

## 開発コマンド

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run state:build
```

## 手動で状態ファイルを更新する流れ

GitHub Actions の `Update State File` を手動実行すると、`public/repo-state.json` が更新されます。

このworkflowは常時自動実行ではありません。必要な時だけ実行する安全寄りの導線です。

## 方針

このアプリは、ユーザーの代わりに危険な操作を勝手に進めるものではありません。

普段の細かい開発作業はできるだけ自動化し、外部連携・本番公開・提出・大きな方向転換などの大事な場面では必ず止まる、やさしい開発管制室を目指します。
